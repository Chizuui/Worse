A desktop GUI for Claude Code, Codex and other AI coding agents

Run Claude Code, Codex, Antigravity, Command Code and any OpenAI-compatible model such as DeepSeek side by side in one native Rust app. When one agent hits its usage limit, the session continues on the next.

Download for Windows macOS Linux Source on GitHub

Free and open source (Apache-2.0). Your transcripts stay on your machine.

What it does

Every agent in one window

Claude Code, Codex, Antigravity, Command Code, a Hermes gateway, or any OpenAI-compatible API (OpenRouter, DeepSeek, Ollama, LM Studio and more). Each session keeps its own agent.

Quota failover

When an agent runs out of quota, Harness continues the same session on the next agent or account in your order, with the transcript intact.

Subagents

Through a built-in MCP server an agent can hand work to other agents, for example a cheap API model for routine edits, and gets the results back automatically.

One history

Conversations live in a local SQLite store, not inside one vendor's CLI: search, resume, fork and import them whichever agent wrote them.

Watch the work

Live code view of the file being edited, diff, git, terminal, and the agent's screen when it uses your computer.

From your phone

Pair a phone once and follow or steer sessions from it, through your own tunnel.
