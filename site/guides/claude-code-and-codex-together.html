How to use Claude Code and Codex together on one project

Claude Code and Codex are good at different things, and each has its own usage limit. Running them in two terminals works, but you end up with two histories and a lot of copy and paste. Worse Harness runs both in one window on the same codebase.

1. Install both agents

  1. Install and sign in to Claude Code (claude) and Codex (codex) as usual.
  2. Install their Agent Client Protocol adapters:
    npm i -g @agentclientprotocol/claude-agent-acp @agentclientprotocol/codex-acp
  3. Download Worse Harness and start it. The first-run setup finds the installed CLIs and can install a missing adapter for you.

Harness never reads your credential files. Each CLI keeps its own login.

2. Open the project

Harness opens the current folder, or the last one you used. To work in another folder use New session ▾ → Open folder…. Sessions are grouped by folder in the Projects tree.

3. Pick an agent per session

The composer has an agent picker. Choose Claude Code for one session and Codex for another. Each session keeps the agent you picked, and you can switch an existing session to the other agent at any time without losing the conversation. Every transcript is stored by Harness in one local database, so you can search, resume and fork it whichever agent wrote it.

4. Let one agent delegate to the other

Harness gives every agent a built-in MCP server, harness-delegate. With it, an agent can start a subagent on another agent and gets the result pushed back automatically. Ask for it in plain words, for example:

Ask Codex to write the unit tests for src/parser.rs while you refactor the CLI.

Subagents claim the files they edit, so two agents do not overwrite each other. You can follow each subagent in the team strip of the session. The number of subagents that run at once is set in Settings → Orchestra.

5. Watch both of them work

The side pane shows the diff of the turn, git, a terminal and a live view of the file the agent is editing, so you can review what either agent changed before you commit.
